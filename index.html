Fork addition: compact stats plus the Advanced Automation planner's settings and live internal data. Appears while Advanced Automation is enabled in the Extras menu.
Stats (compact)
Current loop's stat levels, persistent talent and soulstones — the same numbers as the Regular view, one row per stat.
Stat
Stat name.
 Lv
Current stat level. Resets every loop (to your Imbuement base).
 Talent
Persistent talent level. Never resets; multiplies stat exp gain.
 SS
Soulstones held for this stat. Persistent; multiplies talent exp gain.
Basic automation
Lightweight per-loop assist tools that work on your live queue: rep-gap badges, auto-add reps, and the Buy Mana optimiser. Each has its own toggle; all need "Enable basic automation" (Extras menu) on. Independent of the Advanced planner.


No proposal yet — press Suggest.
Advanced automation settings
All Advanced Automation (planner) parameters. The master on/off switch and the experience gain multiplier stay in the Extras menu.















Objective weights
What the planner values when scoring a candidate loop's outcome (engine ground truth, pre vs post state). Score = sum of weighted terms.
Town
Unlocking a town wins the loop outright (default 1e12).
Unlock
Per action newly unlocked this loop.
 Visible
Per action newly visible this loop.
Frontier
Exp-fraction progress toward probed unlock thresholds (the main grind driver).
 Mana
Log-growth of realized per-loop mana capacity (measured by a harvest-everything capacity probe).
Bank
Measured mana-equivalent value of newly banked good items — a bank pays out every future loop.
 Pool
Expected discovery of new limited-pool items (future banks), from measured per-exec discovery rates.
Relief
Permanent cheapening of routes to other towns (e.g. Old Shortcut reduces Continue On's mana cost). Only active once more than one town is unlocked.
 Headroom
Growth of disposable per-loop mana (capacity minus the pump's cost) vs the last committed loop. Only active once more than one town is unlocked.
 Talent
Total talent exp gained (long-horizon tie-break).
Efficiency
Persistent cost/yield drift on all actions (mana-cost cheapening, gold-yield growth), valued as drift times expected future executions. 0 = off.
 Buffs
Buff levels gained this loop (Ritual, Imbuement, Feast, ...). 0 = off.
Soulstones
Net soulstone flux (grants minus sacrifices); dungeon rolls counted at their ssChance expected value. 0 = off.
 Invest
Gold newly banked with Invest (a permanent interest annuity). 0 = off.
 Talent grind
Above 0, the planner also proposes grind loops on high-expMult (≥4) actions — efficient talent farming. Scored by the Talent weight; this only enables the candidates.

Status: idle
What the planner is doing (planning, last plan's label/score, errors).
Planner internals
Live view of the planning worker's internal state: the last plan round's candidates and score breakdown, the measured per-action knowledge table, probed unlock thresholds, and predictor-vs-engine divergences. Refreshes after each plan; Refresh pulls on demand.
No data yet — run a plan first.
Last plan round
Every candidate the last round confirmed with the real engine: its score and the per-term breakdown (parts), capacity-probe result and pump cost. The winner is what got suggested/installed.
Knowledge table
Per-action empirical profiles measured by rolled-back engine micro-evals: execs, tick cost, mana/gold/reputation per exec, resource grants, price reductions, pool discovery. This is everything the planner knows about what actions do.
Pools & ledgers
Per-town limited-item ledgers: total = discovered pool size, checked = items inspected, good = banked lootables, plus which measured actions grow each pool (discovery). These resource unlocks are what Archipelago will treat as location checks. LF = the resource's "Lootable first" checkbox state.
Unlock thresholds
Perturbation-probed requirements for locked actions: which town-progress/skill dimensions must reach which level. Drives the frontier term and push timing.
Persistent resources
Persistent state that carries across loops but the scorer cannot yet see: buffs, soulstones (per stat + total), invested gold, training limits, effective time, town stones used, and dungeon/trial progression. Observability groundwork — these are read but not scored at default settings.
Predictor divergences
Cases where the Koviko predictor's model disagreed with engine measurement (a correctness canary — engine wins).
